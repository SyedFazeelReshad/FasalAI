# FasalAI

AI-powered crop health intelligence system for early detection and management of crop diseases and pest infestations.

## Target SIH Problem
SIH26131

## Planned Architecture
- **Frontend**: React + Vite
- **Backend**: FastAPI
- **Database**: PostgreSQL
- **ML Model/Service**: Custom ML models for disease/pest detection
- **Weather API**: Integration for weather-based predictions
- **Maps/Location**: Geospatial functionality for field mapping
